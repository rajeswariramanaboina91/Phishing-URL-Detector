About This Project

Phishing URL Detector is a cybersecurity project developed using Python and Flask. It analyzes URLs using rule-based security checks such as HTTPS detection, suspicious keywords, IP address detection, URL length, special characters, domain patterns and embedded credentials.

Note: This project uses basic rule-based analysis. A LOW RISK result does not guarantee that a website is safe.
